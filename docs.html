Documentation

Getting started

  1. Run FayezSpeed.exe as administrator.
  2. Open Boost → choose Lite (safe, recommended) or Power (deeper tuning).
  3. Enable "Create a Windows restore point before each boost" in Settings if you want a system checkpoint.

Game Mode

Game Mode sets the High performance power plan and suspends selected background apps (browsers, chat, cloud) until you stop it. They resume exactly where they left off. Auto-Boost detects games in your library.

Emulator Booster (Game Loop)

Windows-level tweaks (power plan, process priority, GPU preference, fullscreen-optimisation override, RAM trim, cache clean, Hyper-V toggle, engine registry settings). Does not modify the game — no ban risk. For 100% performance also enable VT in BIOS and disable Hyper-V (trade-off: WSL/Docker).

Safety

  • Every change is backed up to %APPDATA%\FayezSpeed\backups\ before applying.
  • Undo individual tweaks or "Restore everything".
  • Fayez Speed does not disable Windows Defender, Windows Update, VBS or Hyper-V automatically (except the opt-in Emulator Booster toggle).

Data location

%APPDATA%\FayezSpeed\ — config, backups, games, benchmarks, activity, logs.

Command-line flags

  • --auto-clean — run scheduled safe cleanup and exit.
  • --selftest — build every page offscreen (CI).
  • --no-elevate — do not request administrator rights.

FAQ

Does it work offline?

Yes. All tweaks, cleaning, monitoring, benchmarking work offline. License validation requires internet (with 14-day offline grace).

Will it get me banned from games?

No. Fayez Speed only uses documented Windows APIs (power plan, priority, registry preferences). It never injects into game processes.
