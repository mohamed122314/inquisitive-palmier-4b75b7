Privacy Policy

Last updated: 2026-11-21

What we collect

Fayez Speed is designed to run locally. The app does not collect telemetry, usage analytics, or personal data by default.

If you purchase a Pro license, the payment processor (Lemon Squeezy) collects billing information per their privacy policy. We receive only: license key, email, and purchase status.

Hardware fingerprint

To prevent license sharing, Pro activation computes a one-way hash of CPU, motherboard, and disk identifiers. This hash contains no personally identifiable information and is used solely for license binding.

Local data

All app data (config, backups, games, benchmarks, activity logs) is stored locally in %APPDATA%\FayezSpeed\. Nothing is uploaded.

Network requests

  • License validation (only if you activate Pro).
  • Update check (GitHub Releases API, optional, 24h cache).
  • DNS benchmark / ping (initiated by you).
  • Windows Defender / Windows Update (system operations).

Cookies / tracking

The website uses no tracking cookies and no analytics by default. If analytics are added later, this policy will be updated.

Questions: support@fayezspeed.com
